# Mob Shopping Campinas — conceito de catálogo

Protótipo local demonstrativo para explorar uma navegação de mobilidade elétrica em três direções visuais. Usa referências externas de fabricantes, não itens confirmados no catálogo ou estoque da Mob Shopping.

## Abrir
Abra `index.html` em um navegador atualizado. Não há dependências de build.

## Interações
- Alternância entre Editorial, Pulso e Garagem.
- Busca e filtros por e-bike, scooter, moto e três rodas.
- Seleção para comparar até três referências.
- Links para as páginas dos fabricantes e contato via WhatsApp.

## Limites
A loja, o número comercial, as unidades e o horário ainda precisam de confirmação. As fotos são reais, obtidas das páginas dos fabricantes e mantidas localmente apenas para esta demonstração. Verifique termos/licenças e obtenha autorização antes de publicar em GitHub Pages, divulgar ou usar comercialmente. O conteúdo não deve ser interpretado como estoque ou representação oficial da Mob Shopping.

Veja `BRIEF_DO_PROJETO.md` e `assets/CREDITS.md`.
